# Tempo Take-Home 2026

A sticky note board prototype built with Next.js, React, TypeScript, and Tailwind CSS.

## Links

- Live demo: [GitHub Pages](https://jessypouliot98.github.io/tempo-take-home-2026/)
- Project description: [docs/Description.md](docs/Description.md)
- Take-home prompt: [docs/Take Home Assessment (FE) - Sticky Notes.pdf](docs/Take%20Home%20Assessment%20(FE)%20-%20Sticky%20Notes.pdf)

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Setup

This repository uses `pnpm`.

1. Install dependencies:

```bash
pnpm install
```

2. Start the local development server:

```bash
pnpm dev
```

3. Open the app in your browser:

```text
http://localhost:3000
```

## Deployment

This repo includes a GitHub Actions workflow at `.github/workflows/deploy-pages.yml` that builds and deploys the site to GitHub Pages on pushes to `main`.
